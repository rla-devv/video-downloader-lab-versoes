Atualização do Video Downloader Lab

Seus vídeos ficam no seu computador

O vídeo vai direto do site para o seu computador. Nada passa pela RLA.dev: nem os links que você cola, nem os vídeos, nem o que você baixa.

A internet é usada para:

  • Baixar o vídeo: o app fala direto com o site do vídeo, como o navegador faria ao assistir.
  • Achar o vídeo dentro de uma página (só quando o link não é de uma plataforma conhecida): abre a página no Microsoft Edge, sem janela, só para encontrar o player.
  • Manter o componente que baixa os vídeos em dia: os sites mudam com frequência; uma vez por dia, ao fechar o app, ele confere se há versão nova desse componente.
  • Ver se há versão nova do Video Downloader Lab: só consulta o número da versão publicada.
  • Instalar, uma única vez: o instalador baixa os componentes do programa (o Python, o ffmpeg e o componente que baixa os vídeos).

Use só para conteúdo que você tem direito de baixar e respeite os termos de cada plataforma. Vídeos protegidos (Netflix, Disney+, Spotify e afins) não são baixados.
